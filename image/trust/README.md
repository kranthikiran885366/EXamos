# ExamOS Phase 3 — Development Trust Keys

**TEST ONLY — NOT FOR PRODUCTION**

This directory holds **development/test** Secure Boot key material generated
by `generate-dev-keys.sh`. These keys are used exclusively in:

- QEMU/OVMF development VMs
- CI pipelines (throwaway keys, destroyed after the run)
- Local developer testing

## Key hierarchy

```
Platform Key (PK)          — root of UEFI Secure Boot trust
    └── KEK                — Key Exchange Key (signs db updates)
          └── db           — Signature Database (signs EFI binaries)
                └── UKI signing key — signs the ExamOS Unified Kernel Image
PCR policy signing key     — separate key for PCR policy assertions
```

## Generating development keys

```bash
bash image/trust/generate-dev-keys.sh
```

This creates self-signed RSA-2048 test certificates valid for 3650 days.
The script sets permissions to 600 on all private key files.

## Production key policy

Production keys are:

- **OFFLINE** — stored on HSMs or air-gapped systems
- **NOT IN GIT** — never committed to this repository
- **NOT IN CI** — CI uses throwaway test keys only
- **Hardware-protected** — PK and KEK on hardware security modules

Do not create production keys as part of P3 development.

## Files generated by generate-dev-keys.sh

| File | Purpose |
|---|---|
| `PK.key` | Platform Key private key (RSA-2048) — TEST ONLY |
| `PK.crt` | Platform Key certificate — TEST ONLY |
| `KEK.key` | Key Exchange Key private key — TEST ONLY |
| `KEK.crt` | Key Exchange Key certificate — TEST ONLY |
| `db.key` | Signature Database private key — TEST ONLY |
| `db.crt` | Signature Database certificate — TEST ONLY |
| `pcr-policy.key` | PCR policy signing key — TEST ONLY |

All files in this directory are `.gitignore`d except this README and the
generator script.
